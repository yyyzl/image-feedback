# Image Feedback

用图片表达修改意见：圈选、点批注、移动图块，然后复制 **原图路径＋精简修改建议**。原生 Rust + Slint 桌面应用，不依赖 Harness、WebView、Node.js 或 Qt 运行时。

[下载发行版](https://github.com/yyyzl/image-feedback/releases) · [构建与安装验证](https://github.com/yyyzl/image-feedback/actions) · [反馈问题](https://github.com/yyyzl/image-feedback/issues)

> 当前为早期开源版本。Windows 安装器尚无发布者证书；macOS DMG 为 **ad-hoc 签名、未通过 Apple 公证** 的版本，首次启动可能被系统拦截。发行页提供的 SHA-256 可检查文件完整性，**不能单独证明发布者身份**；macOS 可通过“系统设置 → 隐私与安全性”允许本应用，不需要关闭全局 Gatekeeper。

## 安装

| 平台 | 下载内容 | 安装方式 |
|---|---|---|
| Windows 10/11 x64 | `ImageFeedback-版本-windows-x64-setup.exe` | 运行安装器，安装到当前用户的 Programs，创建开始菜单入口；可从系统应用列表卸载 |
| macOS 13+，Apple Silicon / Intel | `ImageFeedback-版本-macos-universal-adhoc.dmg` | 打开 DMG，将 **Image Feedback.app** 拖入 **Applications**，推出磁盘后启动 |

安装包包含应用运行所需的非系统内容，用户不需要安装 Rust、Qt、Node.js 或单独的 VC++ Redistributable。Windows 发行构建静态链接 CRT，并检查只导入系统 DLL；macOS 包检查只链接系统动态库。图形兼容性有问题时，Windows 开始菜单有 **Software rendering** 入口。

更新或卸载前，请先复制需要保留的反馈，再退出编辑器及托盘入口；安装器不会强制结束编辑进程。卸载程序不会清理图片或应用数据。详见[安装与数据位置](<docs/INSTALL.md>)。

## 更新

应用启动后会静默检查 GitHub 上最新的正式发行版；托盘或菜单栏常驻时也会定期检查，编辑器与常驻入口共享结果，避免重复请求。成功检查后通常间隔约 24 小时，失败时至少间隔 1 小时再试；也可在编辑器“···”菜单中选择“检查更新”。没有更新或后台检查失败时不会打断编辑。

发现新版本后，可查看更新说明、选择稍后提醒，或主动下载当前平台的安装包。下载完成后会检查文件大小和发行页提供的 SHA-256，但**不会自动运行安装包或关闭应用**：请先复制需要保留的反馈、退出编辑器及托盘/菜单栏，再自行安装。Windows 运行安装程序；macOS 打开 DMG 并将应用拖入 Applications。跨版本更新时会尽可能显示中间版本的重要提醒；如果历史不全，请查看发行页。

更新检查访问 GitHub，会向 GitHub 暴露 IP 等正常连接信息，但不会上传用户图片、批注或本地文件路径。应用不会内置个人 GitHub Token。有关数据位置和签名限制见[安装与数据位置](<docs/INSTALL.md>)。

## 使用

1. 导入或粘贴 PNG/JPEG/WebP/BMP 图片。
2. 选择工具下悬停查看推荐范围，单击采用，或拖动画出自己的范围。也可添加点批注、整体意见。
3. 在右侧写意见；新批注自动滚动定位并聚焦。点击标题可展开或收起，切换、失焦和收起时提交草稿；校验失败会保留文字。每条批注右上角可删除，删除可撤销。拖动已有范围可表达图块移动。
4. 点击“复制反馈说明”：仅包含一条原图路径、必要坐标约定与紧凑的编号意见。

左上角“新建”返回空白工作区，方便开始处理另一张图片；已有批注时会先确认，取消可继续编辑。确认后不能撤销，建议先复制需要保留的反馈。这不会创建项目文件，也不会修改原图或删除已生成的快照。

原图保持不变。磁盘来源未变化时优先给原地址；粘贴图片或原文件发生变化时使用本机保存的原图快照。**本机路径不是公开链接**，发给其他设备或普通聊天客户端时需另附原图。“···”菜单提供原图路径、最近图片快照及可选 Base64 数据；接收工具需要支持解码。

画布右下方提供缩小、放大按钮，不常驻缩放百分比。缩放或平移后，加减左侧出现“恢复初始视图”圆形箭头，恢复后隐藏。触控板双指上下左右滑动平移画布，鼠标滚轮围绕指针缩放；智能预选开关放在更多菜单。左侧保留选择、点批注和平移三个工具。顶部和侧栏操作可通过 Tab 到达，图标按钮有名称与快捷键提示。底部“复制反馈说明”获得键盘焦点或悬停时会显示跨设备使用说明。

[桌面 UI 对齐说明](<docs/UI-WEB-ALIGNMENT.md>)记录批注收起、草稿安全及验证边界。

Windows 使用自绘标题栏。macOS 使用系统标题栏及左上角原生关闭、最小化和缩放按钮；更多菜单在工具栏。macOS 菜单栏使用独立的单色模板图标，由系统自动适配明暗；Dock、Applications 和 Windows 的彩色图标不变。应用消息卡片自绘，文件/目录选择器使用系统原生界面。

关闭编辑器后，独立托盘/菜单栏入口仍保留；从该入口选择“退出图片反馈”会请求关闭编辑器，然后一同退出。有批注时先确认，取消则编辑器与入口都保留，不强杀进程。macOS 的应用级 Quit 也经过编辑器关闭保护。关闭或更换图片后无法再次编辑当前批注，请提前复制需要保留的反馈。

批注栏右上角的“清空当前”保留图片，清除全部批注和文字意见，并复原图块移动；确认后执行，可按 Ctrl/⌘+Z 一次恢复。

常用快捷键：Ctrl/⌘+N 新建、Ctrl/⌘+O 导入、Ctrl/⌘+V 粘贴、Ctrl/⌘+Z 撤销、Ctrl/⌘+Shift+Z 或 Ctrl+Y 重做。撤销和重做也适用于批注输入框；输入文字与画布编辑使用同一套历史。V 选择、P 点批注、H 平移、F 恢复初始视图；空格或中键拖动平移。恢复初始视图会回到刚导入时的居中缩放，让整张图片完整显示在当前画布中。

## 范围与隐私

- 图片和批注在本地处理，不上传；无账号、遥测、自动安装更新、自动开机启动或网络模型调用。默认会联网检查 GitHub 正式发行版，用户也可以主动下载；连接所暴露的信息及更新方式见上文。托盘与编辑器通过带随机令牌的本机回环连接协调退出。
- 智能推荐是图像启发式算法，不是 OCR、DOM 识别或语义模型；复杂纹理可能不推荐，始终可手动框选。
- 目前只支持图块平移，不支持旋转/缩放、保存或打开项目、导出反馈包、跨重启恢复批注或崩溃恢复。旧版 `.ifp` 文件不会被删除，但此版本不能打开它们。
- 单图上限4000万像素、源文件64 MiB、最多1000个标记；大图仍需相应像素内存。
- 复制时的图片快照保留在用户应用数据目录，可自行清理；清理会使以前复制的快照路径失效。

## 从源码构建

需要 Rust 1.95.0 和对应平台编译工具：Windows 为 MSVC Build Tools + Windows SDK，macOS 为 Xcode Command Line Tools。开发依赖不属于最终用户运行依赖。

```sh
cargo build --release --locked
cargo test --release --locked
```

[打包、CI与验证方法](<docs/BUILD.md>)介绍 Windows 安装器、macOS Universal DMG、实际安装/卸载回归及测试边界。贡献前请阅读[贡献说明](<CONTRIBUTING.md>)。
