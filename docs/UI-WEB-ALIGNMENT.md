# 桌面 UI 与网页试验结果对齐

## 方向与范围

以 `v0.1.2`（`0c1856f`）为基线，吸收网页端已经确认的交互和样式。让图片成为主角，批注信息按需展开，常用动作保持可发现。第一批调整顶部共享控件、左侧重复入口、右侧批注及固定复制区；不改变项目格式、原图坐标、图块移动、交付内容或窗口控制方式。

- 顶部新建、导入、打开统一为描边文件按钮；撤销、重做使用有名称与快捷键提示的弱化图标按钮。保存与导出分别保留，自适应间隔优先让位给按钮。
- 左侧仅保留选择、点批注、平移；显示全图保留在右下缩放组及画布 `F` 快捷键。智能预选开关保留。
- 右侧统一宽 330、左右边距 20。收起卡片高 48，仅显示编号、单行摘要、箭头及独立删除区；空白文字显示“未填写意见”，摘要不修改原文。
- 同时展开一条，显示类型、编辑状态、详情及多行输入。短文字从 180 高起，长文字扩大至 252，正文内部滚动。编号超过两位时扩成胶囊，支持 1000 条。
- 删除和完成不再占据卡片底部：删除统一放在顶部，点击标题提交并收起，失焦提交，Ctrl/⌘+Enter 提交并结束，Esc 取消未提交的文字并返回画布。
- 固定底部复制按钮使用统一图标、描边与边距；悬停或键盘焦点均可发现本机路径及跨设备交付说明。

## 草稿、历史与焦点

收起、切换、删除、保存和复制等操作先提交草稿；失败保留草稿、选中项及恢复编辑的入口，不执行后续破坏操作。删除仍走同一业务入口：文字严格为空可直接删除，非空确认，均可撤销。危险确认默认选择取消。清空当前保留图片并支持一次撤销；新建、换图、打开及关闭继续使用保存／不保存／取消保护。

列表视图按稳定数据 ID 更新已有行，显示编号仍仅代表当前次序。普通画布重绘不重建正在使用的输入框，避免重置光标。输入框使用 Slint 原生 TextInput，保留多行、选区、输入法预编辑与上下文菜单；输入法组合期间暂停会销毁编辑器的应用动作。Delete / Backspace 在文字焦点下用于编辑文字。

优化构建中大批量创建行可能分多次完成布局；当前项在卡片位置或列表高度更新后修正滚动，不使用持续滚动定时器。手动滚动不触发这些布局值变化，普通重绘不会把列表拉回编辑器。删除前面的条目改变显示编号时，也重新映射当前项并定位。

校验失败弹窗保持模态焦点，Ctrl/⌘+Enter 不把焦点移到弹窗后面。输入框可见蓝色焦点外框，控件补充按钮名称、启用和展开状态；这些语义仍需平台辅助技术专项验收。

## 视觉约定

沿用平台系统字体，不下载字体。主蓝 `#4562e5`，hover `#3653d7`；画布底 `#eff1f5`；侧栏编号 `#dc2b39`；画布标记保持原有 `#dc5147`。输入框焦点 `#7085eb`，卡片选中底 `#f5f7ff`、边 `#cbd5ff`。普通按钮约 36 高，卡片圆角 9，图标采用统一 1.6 线宽 SVG。

按钮背景及边框使用 100 ms 过渡、工具选中背景 120 ms、批注卡片背景和边框 120 ms；禁用按钮立即切换，避免过渡期间出现灰字叠蓝底。没有改变画布几何或增加展开动画，以免长列表定位和输入光标跳动。

一轮独立截图评审采用存量界面润色标准，不评分。保留整体结构与文案；修正了画布内层底色及空态禁用过渡。删除的内容仅为左侧重复显示全图及卡片底部重复删除／完成按钮，没有删除业务能力。

## 验证与边界

Rust 回归覆盖草稿提交／失败保留、收起／切换、稳定 ID 列表更新、空白摘要和原文保留；既有保存、清空、撤销和交付测试继续运行。

新增 `--ui-smoke <目录>` 窗口回归，接入 Windows 安装验证及 macOS 复制应用验证。使用真实 Slint 窗口和场景键盘／指针事件，检查收起提交、光标保留、文字删除、Esc、Ctrl/⌘+Enter、失败恢复、独立删除、取消／撤销、1000 条及 1000 × 688 最小窗口。复制失败使用隔离剪贴板，不覆盖用户剪贴板。结果和截图写入指定目录的 `ui-report.json` 及 PNG。

本机验证使用隔离应用数据；窗口模式有 60 秒进程超时。截图及运行报告放在忽略的 `artifacts/shortcuts-*` 目录，不混入用户图片或提交。实际平台结果见提交或 CI 记录；Windows 的 Slint 缩放覆盖不能替代 macOS 运行验证。

场景回归不等于操作系统鼠标 E2E。真实中文输入法候选、多屏与系统字体变化仍需人工专项检查。当前构建未启用 Slint 的平台 accessibility 后端，补充语义与键盘焦点不等于已通过屏幕阅读器认证；本批不扩大依赖和安装包动态库范围。

macOS 并行回归另外暴露了交付测试临时目录仅依赖时间戳的问题；测试目录追加进程内原子序号，避免时钟精度有限时测试相互清理。此修复只影响测试隔离，不改变交付逻辑。
