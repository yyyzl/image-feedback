# 安装、更新与用户数据

## 检查更新

应用启动后和常驻期间会后台检查 GitHub 最新正式发行版；也可在编辑器“···”菜单中手动检查。只有用户选择下载时才下载对应平台的安装包，并核对文件大小和发行页提供的 SHA-256。检查或下载会连接 GitHub，GitHub 可见 IP 等正常连接信息；应用不上传图片、批注或本地文件路径，也不使用个人 Token。

下载/校验窗口右上角 × 只收起窗口，下载继续；关闭整个编辑器会中断下载。下载完成后显示“更新已准备好”，选择“稍后安装”后顶部保留入口，重启应用也会恢复有效的已下载更新。

**Windows**：点击“现在安装”后，如有批注，先选择返回编辑或明确同意退出。安装助手重新校验文件，准备失败时保留当前编辑内容；准备成功后安全退出编辑器和托盘，再打开安装向导，不再要求用户打开目录自行寻找安装包。不强杀编辑进程，也不会绕过 Windows 安全提示。安装向导中的启动选项仍由用户决定。

**macOS**：主操作为“打开安装包”，直接打开 DMG，仍需退出应用并手动替换；尚未实现自动替换或 Sparkle 集成。

SHA-256 与安装包同由 GitHub 发行页提供，只能检查完整性，**不能代替独立更新签名或证明发布者身份**。Windows 安装器尚未代码签名，安装确认页会说明这一限制；macOS 使用 ad-hoc 签名且未公证。系统可能提示风险，请自行核对发行来源。

旧版本如果没有此功能，需先手动安装一次包含更新检查功能的新版本。

## Windows

从[发行页](https://github.com/yyyzl/image-feedback/releases)下载 x64 安装器，核验 SHA-256 后运行。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ImageFeedback`，无需管理员权限。开始菜单包含正常入口和软件渲染兼容入口；桌面快捷方式可选。

安装内容包括静态 CRT 可执行文件、许可和依赖清单，不要求最终用户安装 Rust、Qt、Node.js、MSVC Build Tools 或单独 VC Redistributable。Windows 自带系统库和字体不重复打包。安装器注册卸载信息和 App Paths，不抢占 PNG/JPEG 等图片关联。

应用内更新会协助协调退出。手动安装或卸载前，仍需先复制需要保留的反馈，从托盘菜单选择“退出图片反馈”，并在有批注时确认；取消确认会保留编辑器和托盘入口。安装器检测运行中的应用，不调用 Restart Manager 强杀它。通过系统“已安装的应用”卸载；应用文件、注册项与快捷方式被移除，用户数据保留。

当前发行文件没有代码签名证书，SmartScreen 可能显示未知发布者；这不等于已获得微软信任或通过安全认证。

## macOS

打开 Universal DMG，将 **Image Feedback.app** 拖到 **Applications**，推出磁盘，再从 Applications 启动。应用包包含可执行文件、图标和许可，不依赖构建目录、Homebrew、Rust、Qt 或 Node。

当前构建没有 Developer ID / Apple 公证，只有 ad-hoc 完整性签名。首次下载可能被 Gatekeeper 阻止，可在“系统设置 → 隐私与安全性”针对本应用选择允许打开。不要关闭全局 Gatekeeper；发行页同时提供 SHA-256。完整签名、公证版本需要项目持有人提供 Apple Developer 凭据，不能把 ad-hoc 验签当成公证。

窗口使用原生左上角 traffic-light 控制，编辑器是正常 Dock 应用，常驻入口使用菜单栏 accessory 身份。关闭编辑器后菜单栏仍保留；从菜单栏选择“退出图片反馈”会先请求关闭编辑器，再一同退出。取消批注丢弃确认时，两者均保留；原生窗口关闭和应用级 Quit 也接入批注丢弃确认。

更新时先复制需要保留的反馈，再退出编辑器和菜单栏入口，然后替换 Applications 中的 `.app`。卸载可将 `.app` 移到废纸篓；不会自动删除用户项目或应用数据。

## 用户数据

| 平台 | 应用数据目录 |
|---|---|
| Windows | `%LOCALAPPDATA%\image-feedback-slint` |
| macOS | `~/Library/Application Support/image-feedback-slint` |

目录名保留开发期标识，以便升级沿用已有数据。更新检查的状态保存在 `update-check.json`；`ready-update.json` 保存稍后安装的发行信息和校验记录。用户主动下载并验证通过的安装包保存在 `updates` 的独立子目录，可在完成安装后自行删除。Windows 的独立安装助手位于 `update-helpers`，下次安装准备时尝试清理旧副本；交接或安装失败详情写入 `last-update-error.txt`。取消或校验失败的未完成下载会清理；突然断电或强制终止进程可能留下临时文件。复制反馈产生的原图及编号参考图快照位于 `feedback-deliveries`，不自动清理；旧版的 `.ifp` 项目与反馈包不会被删除，但此版本不再打开项目或导出反馈包。

本机路径仅适合同机读取。发给其他电脑时另附原图；Base64 只有在接收端支持解码时适用。不要直接修改用于既有意见定位的图片快照。
