# 图块自由变换

## 使用与边界

在选择工具下框选或采用推荐范围，选中后：

- 拖动范围内部移动；拖动任一角点等比缩放，对角保持固定。
- 拖动上方圆形手柄旋转，也可拖动任一角点外侧旋转；角点本身优先缩放。旋转时按住 Shift 可按 15° 吸附。
- 变换后仍可拖动或再次缩放、旋转。空格／中键拖动画布，滚轮以指针为锚缩放画布，与图块变换分离。
- 每次完成手势形成一个撤销步骤；Esc 或失焦取消正在进行的手势，不提交预览。

选区是**原图中的矩形像素，包含背景**，不是识别出的独立图层；原位置以灰色占位，并不进行背景修复。原图文件不被修改。目标允许移出图片边界，画布上能看见的部分仍可调整；编号参考图保持原图尺寸，越界部分裁剪，复制说明会提示。过小或过大的缩放受到安全限制；不支持翻转或非等比拉伸。

界面不展示比例或角度。复制文本在图块缩放或旋转后写入目标矩形、缩放、目标中心和顺时针角度，其中目标矩形是**旋转前**的矩形；原图像素坐标可为小数。默认复制仍只包含一条原图路径，不自动附带参考图路径；图片快照和参考图保存在本机，跨设备须另附图片。

## 实现约定

- `AnnotationKind::Block` 保存固定 source、旋转前 target 和以 target 中心为轴的顺时针角度；旧数据没有角度时默认为零。首次移动、缩放或旋转才将区域变为图块。来源仍需在原图内，多个图块来源不允许重叠。
- `src/transform.rs` 是命中、控制点、对角锚定、逆坐标变换和参考图几何的共同约定。手柄和角外命中区域按屏幕尺寸计算；顶部手柄接近视口边缘时会保持在可见范围。
- 软件渲染器不支持任意 item 旋转，因此旋转图块使用受尺寸与缓存预算限制的 CPU 位图，轮廓和手柄使用路径与屏幕坐标绘制。手势期间使用较快预览，结束后使用平滑采样；原图与参考图不依赖 Slint 的旋转能力。
- 参考图先覆盖所有来源，再按标记顺序合成目标和编号。采样支持透明像素并在插值时使用预乘 alpha；目标与参考图按原图边界裁剪。复制文本会标识越界。

## 验证

`cargo test --release --locked` 覆盖旋转命中、四角等比缩放锚点、历史、旧数据默认角度、非法几何和参考图像素。`--smoke-test` 在真实 Slint 窗口中通过场景指针事件检查新选区直接缩放／旋转、两个旋转入口、四角、旋转后缩放与拖动、边缘手柄、视图平移、撤销重做及快照。安装回归在 Windows、Apple Silicon 和 Intel 使用软件渲染器运行该场景。

Windows 本机也可运行：

```powershell
cargo build --locked
pwsh -File scripts/verify-transform-input.ps1
```

该脚本启动独立数据目录的 debug 测试进程，使用操作系统鼠标及键盘事件，并恢复原先的鼠标位置；不会使用系统剪贴板或关闭用户已有编辑器。它会置前测试窗口并移动鼠标，请不要同时操作电脑。它验证一次真实 Windows 输入链，不等同于所有触控板、输入法、DPI、多屏和 macOS 物理设备验收。`src/pointer_probe.rs` 仅编译进 debug 程序，发行构建不包含该探针。
