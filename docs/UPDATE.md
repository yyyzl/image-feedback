# 更新下载与 Windows 安装交接

## 用户流程

启动后台检查 → 查看发行说明 → 明确点击下载 → 下载及 SHA-256 校验 → 现在安装 / 稍后安装。

- 下载进度由左向右增长；× 仅收起，不取消下载。
- 下载完成不会抢焦点。顶部状态入口可重新打开确认框。
- 有批注时复用 `PendingAction` 保护。返回编辑不启动助手、不清除草稿；确认只授权安装，准备失败前不修改文档。
- 准备安装期间暂时阻止重复操作。失败保留编辑器并提供重试安装和重新下载。
- `ready-update.json` 保存发行信息、文件大小和下载时验证的 SHA-256。重启时检查目标平台、更新版本、路径和文件大小；执行前助手再计算 SHA-256。
- macOS 保持真实的 DMG 打开/手动替换流程，不显示虚假的自动安装承诺。

## Windows 进程协议

1. `update_ui` 的主操作回调交给编辑器，经过输入法、后台工作和未保留反馈保护。
2. 编辑器在工作线程中复制当前可执行文件到应用数据目录的 `update-helpers`，避免正在运行的助手锁住将被替换的安装文件。
3. 助手专用入口在正常 UI 和 `ImageFeedback.Running` 互斥量创建之前执行。父进程通过私有 stdin 管道传递安装计划，不拼接 shell 命令。
4. 助手获取 `update-install.lock`，重新验证下载路径、Windows 安装包命名、大小与 SHA-256。只读文件句柄禁止写入/删除，保持到安装结束，避免校验后文件被替换。获取编辑器及托盘进程句柄后返回 `READY`。
5. 编辑器只在收到 `READY` 后发送 `INSTALL` 并退出。准备失败仍保持原窗口和文档。未收到提交、管道断开或未提交的助手被回收时，不运行安装程序。
6. 助手等待编辑器**进程**结束，然后通过独立 `resident-control.json` 端点请求托盘退出。端点沿用回环 TCP + 随机令牌认证，不传图片或批注。托盘仍使用已有协调退出逻辑，失败/取消不会强杀进程。
7. 助手检查编辑器锁、托盘锁、应用运行互斥量，并等待托盘进程结束。超时或拒绝退出则不执行安装器。
8. 启动安装器，保留系统发布者/SmartScreen 提示与安装向导。不使用静默强制安装。安装期间保持启动门锁，避免用户误开旧版本。
9. Inno 的安装后启动项带 `--after-update-install`，仍为 `nowait`。新进程在创建运行互斥量前短暂等待门锁；安装器结束、助手释放门锁后才正常启动。该参数不会绕过锁。

## 失败与信任边界

- 准备超时只终止本次创建且尚未提交的助手，绝不终止用户编辑器或托盘。
- 提交后退出超时不运行安装器。安装器启动失败、取消或非零退出会记录 `last-update-error.txt`，尝试重新打开应用并展示说明，更新文件仍保留。
- 这不是事务式自动替换器：不承诺安装器部分失败时回滚所有安装文件。必要时从官方发行页重新安装。
- SHA-256 是完整性校验，不是发布者签名；当前 Windows 安装器未代码签名。安装确认明确说明这一点，用户必须单独同意执行。正式发布信任链仍需要签名证书及发布密钥管理。
- 当前没有自动替换 macOS 应用、Sparkle、签名或公证能力。

## 回归覆盖

- Rust 单测：文件大小/哈希/路径校验、校验句柄禁止替换、启动锁、超时、IPC 端点隔离/超时、稍后安装恢复、批注和非法草稿取消保护。
- 原生 Slint `--update-smoke`：滚动/键盘、进度左对齐、稍后安装、安装保护、取消和真实助手准备失败；不连接网络、不执行安装包。
- `scripts/test-update-handoff.py`：真实编辑器、托盘、助手进程 + 只写标记的本机编译安装器替身；隔离用户数据和运行互斥量，不安装软件、不更改注册表。
- 仍需独立环境验收：真实 Inno 跨版本升级、安装后的新版本启动、系统安全提示、签名，以及 macOS DMG 行为。
