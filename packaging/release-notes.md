# Image Feedback v0.2.0

Windows 和 macOS 本地图片反馈编辑器：导入图片、标注意见，再复制反馈给 AI 或协作者。

## 升级前请注意

**本版本移除了项目保存／打开及反馈包导出功能，不能继续编辑旧版 `.ifp` 项目。** 更新不会主动删除已有 `.ifp` 文件或旧反馈包。需要继续编辑旧项目时，请先备份文件，并在升级前使用旧版完成编辑、复制需要保留的反馈。

批注只保留在当前编辑会话，关闭或换图后无法恢复编辑；有批注时会先要求确认，默认选择取消。请在关闭前复制需要保留的反馈；原图不会被修改。

## 本次更新

- 简化主流程，移除项目与反馈包入口及相关功能，保留导入图片、批注和复制反馈。
- 调整批注栏：意见可展开或收起，切换和收起时提交草稿；单条批注可删除并撤销，清空当前反馈仍可一次撤销。
- 画布缩放控件移至右下角；缩放或平移后可恢复初始视图。触控板双指平移画布，鼠标滚轮围绕指针缩放。
- “复制成功”提示移至复制按钮附近。复制内容包括本机原图路径和精简修改意见；跨设备或发给普通聊天客户端时，请另附原图。应用仍会在本机保留原图和编号参考图快照，不再自动生成反馈包。
- 托盘／菜单栏选择“退出图片反馈”时，会先请求关闭编辑器再退出常驻入口；有批注时可以取消，取消后两者都会保留，不会强杀进程。

## 下载与安装

- **Windows 10/11 x64**：下载 `ImageFeedback-0.2.0-windows-x64-setup.exe` 并运行安装器。升级前请复制需要保留的反馈，退出编辑器和托盘入口；安装器不会强制结束正在编辑的程序。
- **macOS 13+，Apple Silicon / Intel**：下载 `ImageFeedback-0.2.0-macos-universal-adhoc.dmg`，打开后将 Image Feedback.app 拖入 Applications，推出安装盘再启动。
- 使用同名 `.sha256` 文件核验下载完整性。卸载不会清理用户图片或应用数据。

安装包包含应用所需运行内容，不要求用户安装 Rust、Qt、Node.js 或单独的 VC++ Redistributable。Windows 静态链接 CRT；macOS 安装包包含 arm64 和 x86_64 两种架构。

## 验证与签名说明

发行工作流运行 Rust 测试，检查动态库，并验证 Windows 安装、修复安装、卸载和托盘退出；macOS 分别在 Apple Silicon 和 Intel 上验证复制安装后的应用及窗口交互。窗口与托盘回归使用实际应用进程和场景事件，不等同于物理输入、真实输入法、干净虚拟机或最低系统版本认证。

Windows 安装器尚未签名；macOS 应用为 ad-hoc 签名，尚未通过 Apple 公证。macOS 首次启动可能需要在“系统设置 → 隐私与安全性”选择允许打开。

图片在本机处理，不上传。托盘与编辑器仅通过带随机令牌的本机回环连接协调退出，不通过该连接传输图片或批注；本版本不包含自动更新。
