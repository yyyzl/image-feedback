# Image Feedback v0.2.2

Windows 和 macOS 本地图片反馈编辑器：导入图片、标注意见，再复制反馈给 AI 或协作者。

## 本次更新

- 新增后台更新检查：启动后和托盘／菜单栏常驻期间检查 GitHub 最新正式发行版；有新版本时以轻提示告知，不打断编辑。也可在编辑器“···”菜单中手动检查。
- 可在应用内查看版本说明和升级提醒。长说明支持滚动及键盘浏览；跨版本升级会尽可能展示中间版本的重要提醒，历史不完整时会提示查看发行页。
- 可选择下载当前平台的安装包，下载后检查文件大小和 SHA-256。**应用不会自动运行安装包、退出编辑器或替换应用**；请复制需要保留的反馈、退出编辑器及托盘／菜单栏，再手动安装。
- 更新检查连接 GitHub，GitHub 可见 IP 等正常连接信息；应用不会上传图片、批注或本地文件路径，也不会内置个人 GitHub Token。

## 升级前请注意

**从 v0.2.0 起，应用不再支持项目保存／打开及反馈包导出，v0.2.2 也不能打开旧版 `.ifp` 项目。** 更新不会主动删除已有 `.ifp` 文件或旧反馈包。需要继续编辑旧项目时，请先备份文件，并在升级前使用旧版完成编辑、复制需要保留的反馈。

批注只保留在当前编辑会话，关闭或换图后无法继续编辑；有批注时会先要求确认，默认选择取消。请在确认丢弃前复制需要保留的反馈。跨设备或发给普通聊天客户端时，请另附原图；应用也会在本机保留原图和编号参考图快照。

**v0.2.1 和更早版本没有更新检查功能**，需要先从本发行页手动下载安装一次包含更新功能的版本。

## 下载与安装

- **Windows 10/11 x64**：下载 `ImageFeedback-0.2.2-windows-x64-setup.exe` 并运行安装器。升级前请复制需要保留的反馈，退出编辑器和托盘入口；安装器不会强制结束正在编辑的程序。
- **macOS 13+，Apple Silicon / Intel**：下载 `ImageFeedback-0.2.2-macos-universal-adhoc.dmg`，打开后将 Image Feedback.app 拖入 Applications，推出安装盘再启动。
- 使用同名 `.sha256` 文件检查下载完整性。SHA-256 与安装包来自同一发行页，**不能单独证明发布者身份**。卸载不会清理用户图片或应用数据。

安装包包含应用所需运行内容，不要求用户安装 Rust、Qt、Node.js 或单独的 VC++ Redistributable。Windows 静态链接 CRT；macOS 安装包包含 arm64 和 x86_64 两种架构。

## 验证与签名说明

发行工作流运行 Rust 测试，检查动态库，并验证 Windows 安装、修复安装、卸载、托盘退出及更新窗口；macOS 分别在 Apple Silicon 和 Intel 上验证复制安装后的应用及窗口交互。更新窗口回归使用模拟发行数据，不运行安装包。窗口与托盘回归使用实际应用进程和场景事件，不等同于物理输入、真实输入法、干净虚拟机或最低系统版本认证。

Windows 安装器尚未签名；macOS 应用为 ad-hoc 签名，尚未通过 Apple 公证。macOS 首次启动可能需要在“系统设置 → 隐私与安全性”选择允许打开。请核对发行来源及系统安全提示。
