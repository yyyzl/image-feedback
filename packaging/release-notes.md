# Image Feedback v0.2.4

本次重点修复自动更新体验：下载窗口可以收起，更新准备好后可选择稍后安装；Windows 用户确认后由应用安全退出并打开安装向导，不再要求自己去下载目录寻找安装包。

## 更新流程改进

- **启动检查**：应用启动后后台检查新版本；编辑器与托盘协调请求，复用最近 60 秒内的检查结果，不重复请求、不抢编辑焦点。
- **下载进度**：进度条从左向右增长；移除重复的“后台进行”和“取消下载”按钮。右上角 × 只收起更新窗口，顶部保留进度入口；退出整个编辑器仍会中断下载。
- **稍后安装**：下载并校验完成后可选择“稍后安装”。顶部保留“更新已准备好”，有效的下载记录在应用重启后也会恢复。
- **Windows 现在安装**：点击后先处理未保留的批注；选择返回编辑不会启动安装。确认继续后，独立助手重新检查安装包，等待编辑器和托盘进程真正退出，再打开安装向导，不强杀进程。
- **失败处理**：安装准备失败时保留编辑内容，支持重试安装或重新下载；退出超时则停止安装。安装器取消或失败时保留更新文件并提示后续处理，不宣称安装成功。
- **macOS 如实提示**：下载完成后直接打开 DMG，仍需退出应用并拖入 Applications；本版没有自动替换或 Sparkle 集成。

## 升级前请注意

**v0.2.2 / v0.2.3 可检查更新和下载，但安装交接尚未实现。因此从这些版本升级到 v0.2.4 时，仍需手动退出编辑器及托盘／菜单栏，再运行安装包一次；安装 v0.2.4 后，Windows 后续更新才会使用新的安装交接流程。** v0.2.1 及更早版本需从本发行页手动下载安装。

**从 v0.2.0 起，应用不再支持项目保存／打开及反馈包导出，v0.2.4 也不能打开旧版 `.ifp` 项目。** 升级不会主动删除已有 `.ifp` 文件或旧反馈包；需要继续编辑旧项目时，请先备份，并用旧版完成编辑、复制需要保留的反馈。

批注只保留在当前编辑会话。安装确认中的“仍要退出并安装”会结束该会话，之后即使取消安装向导，也不能恢复已丢弃的批注。请先复制需要保留的反馈。跨设备发送时另附原图，本机路径不是公开链接；原图和已生成的反馈快照不会被更新流程删除。

## 下载与安装

- **Windows 10/11 x64**：下载 `ImageFeedback-0.2.4-windows-x64-setup.exe`，退出编辑器和托盘后运行安装器。安装器不强制结束正在编辑的程序，安装完成后可选择启动应用。
- **macOS 13+，Apple Silicon / Intel**：下载 `ImageFeedback-0.2.4-macos-universal-adhoc.dmg`，打开后将 Image Feedback.app 拖入 Applications，推出安装盘再启动。
- 使用同名 `.sha256` 文件检查下载完整性。安装包包含应用运行所需内容，不要求用户安装 Rust、Qt、Node.js 或单独的 VC++ Redistributable；卸载不清理用户图片或应用数据。

## 验证与安全边界

本次新增更新记录恢复、安装前文件校验、IPC 超时和批注保护回归；Windows 原生窗口验证安装确认、取消及助手准备失败，隔离进程测试验证编辑器和托盘退出后才执行安装器替身。替身只写测试标记，不安装软件。发行工作流另运行实际 Windows 安装、修复、卸载与原生窗口验证，并分别验证 macOS Universal 包的 Apple Silicon 和 Intel 运行。

进程交接测试不等同于真实跨版本升级或系统安全信任认证；安装器部分失败时不承诺自动回滚所有安装文件。

**SHA-256 只能检查完整性，不能证明发布者身份。** Windows 安装器尚未代码签名；macOS 为 ad-hoc 签名，未通过 Apple 公证。Windows 安装确认会说明签名限制，不绕过 SmartScreen；macOS 首次启动可能需要在“系统设置 → 隐私与安全性”选择允许打开。请核对发行来源及系统安全提示。
