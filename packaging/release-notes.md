# Image Feedback v0.2.3

这次更新让图片里的选区可以直接移动、等比缩放和旋转：看着画布调整到合适的位置，再写批注，不需要手动填写比例或角度。

## 新功能：图块自由变换

- **移动**：选中范围后，拖动选区内部；缩放、旋转之后仍可以继续拖动。
- **等比缩放**：拖动选框四角的小方块，对角保持固定；再次缩放时保持当前旋转方向，不会拉伸变形。
- **旋转**：保留选框上方的圆形旋转手柄；也可以把鼠标移到任意角点外侧，看到旋转光标后拖动，操作方式类似 Photoshop。旋转时按住 Shift 可按 15° 吸附。
- **画布与图块分开操作**：空格或鼠标中键拖动画布，滚轮围绕指针缩放画布，不会改变图块变换；变换手柄的可操作范围不随画布缩放变小。
- **撤销与重做**：每次完成的移动、缩放或旋转均可撤销、重做；右侧批注仍与同一标记关联。
- **复制反馈和参考图**：复制的说明保留原图坐标，并在需要时记录图块的缩放、旋转和目标位置，便于接收方重现；本机生成的编号参考图也反映最终变换。编辑界面不显示或要求输入这些数值。

### 使用时请注意

- 图块是选区内的**矩形像素，包含背景**，不是自动识别的独立图层或抠图。变换后原位置显示灰色占位；应用不会自动修补背景。原图文件始终保持不变。
- 图块可以部分移出原图，画布里仍可调整；参考图只有原图大小，超出边界的部分会被裁剪，复制说明会提示这一点。
- 缩放为等比缩放，不支持翻转或单独拉伸宽高。图片本机处理，不会因为图块变换上传图片或批注。

## 升级前请注意

**从 v0.2.0 起，应用不再支持项目保存／打开及反馈包导出，v0.2.3 也不能打开旧版 `.ifp` 项目。** 更新不会主动删除已有 `.ifp` 文件或旧反馈包。需要继续编辑旧项目时，请先备份文件，并在升级前使用旧版完成编辑、复制需要保留的反馈。

批注只保留在当前编辑会话，关闭或换图后无法继续编辑；有批注时会先要求确认，默认选择取消。请在确认丢弃前复制需要保留的反馈。跨设备或发给普通聊天客户端时，请另附原图；本机路径不是公开链接。应用也会在本机保留原图和编号参考图快照。

从 v0.2.2 可在应用“···”菜单检查更新并下载；下载后仍需自行退出编辑器和托盘／菜单栏并手动安装。**v0.2.1 和更早版本没有更新检查功能**，请从本发行页手动下载安装。

## 下载与安装

- **Windows 10/11 x64**：下载 `ImageFeedback-0.2.3-windows-x64-setup.exe` 并运行安装器。升级前请复制需要保留的反馈，退出编辑器和托盘入口；安装器不会强制结束正在编辑的程序。
- **macOS 13+，Apple Silicon / Intel**：下载 `ImageFeedback-0.2.3-macos-universal-adhoc.dmg`，打开后将 Image Feedback.app 拖入 Applications，推出安装盘再启动。
- 使用同名 `.sha256` 文件检查下载完整性。SHA-256 与安装包来自同一发行页，**不能单独证明发布者身份**。卸载不会清理用户图片或应用数据。

安装包包含应用运行所需内容，不要求用户安装 Rust、Qt、Node.js 或单独的 VC++ Redistributable。Windows 静态链接 CRT；macOS 安装包包含 arm64 和 x86_64 两种架构。

## 验证与签名说明

发行工作流运行 Rust 回归和实际安装后的原生窗口测试；图块变换覆盖缩放、两个旋转入口、四角、变换后拖动、画布平移、撤销重做、越界以及参考图。Windows 本机另以操作系统鼠标和键盘事件测试上述主要交互；自动场景事件不等同于每种物理设备或系统版本的实机认证。macOS 的 Universal 包分别在 Apple Silicon 和 Intel 运行验证。

Windows 安装器尚未签名；macOS 应用为 ad-hoc 签名，尚未通过 Apple 公证。macOS 首次启动可能需要在“系统设置 → 隐私与安全性”选择允许打开。请核对发行来源及系统安全提示。
